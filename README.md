# Thesis with DROID — `fine-tuning` branch

This branch contains code used during the fine-tuning phase of the thesis. It is not intended to run the robot — for that, see the `robotiq-gripper` branch which is the main benchmark branch.

The code here covers experimental and development work done during fine-tuning, including scripts such as episode visualization.

Each branch has its own README. See the `robotiq-gripper` branch for the full branch overview table.
